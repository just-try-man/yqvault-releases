# YQvault

Release downloads for YQvault. Open the [latest release](https://github.com/just-try-man/yqvault-releases/releases/latest) and pick the file for your device.

| Device | File |
| --- | --- |
| Windows 10 or 11 | `YQvault-Setup-<version>.exe` |
| Mac (Apple silicon and Intel, macOS 10.15 or later) | `YQvault-<version>.dmg` |
| Android 7 or later | `YQvault-<version>.apk` |

Installed copies check this page every few hours, download new versions in the background and offer to restart. You only download a file here once.

## Installing

**Windows.** Run the setup. If SmartScreen stops it, choose **More info**, then **Run anyway**. Running a newer setup over an installed copy updates it in place.

**Mac.** Open the disk image and drag YQvault to Applications. The first time you open it, macOS may say it can't check the app: open **System Settings > Privacy & Security** and choose **Open Anyway**.

**Android.** Open the APK on your phone. Android asks you to allow installs from the app you opened it with (your browser or file manager); allow it, then tap **Install**. When YQvault updates itself later, Android may ask you to confirm once more.
